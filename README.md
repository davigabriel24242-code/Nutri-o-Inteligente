Sobre o BEMIA
O BEMIA é um aplicativo mobile de nutrição e bem-estar pensado para ajudar as pessoas a registrar refeições, acompanhar metas e entender seus hábitos ao longo do tempo.
A experiência foi concebida para unir uma interface acolhedora a ferramentas práticas de acompanhamento, sem transformar o cuidado diário em uma competição ou em uma fonte de pressão.
O que o projeto pretende oferecer
- Diário alimentar: registro e consulta de refeições e ingredientes.
- Acompanhamento nutricional: calorias e macronutrientes com valores apresentados como estimativas quando apropriado.
- Registro flexível: entrada manual e, nas etapas futuras, captura por foto, leitura de código de barras e voz.
- Bem-estar diário: acompanhamento de hidratação e atividade física.
- Jejum configurável: temporizador e lembretes de acordo com as preferências escolhidas pelo usuário.
- Peso e progresso: histórico de medições e metas pessoais.
- Estatísticas: resumos de tendências e metas.
- Privacidade e controle: preferências claras e confirmação para ações destrutivas.
O projeto está em desenvolvimento. Os itens acima descrevem o escopo planejado; cada integração será identificada como disponível somente quando estiver implementada e testada.

Começar a desenvolver
Depois de clonar o repositório e criar/configurar o projeto Expo, instale as dependências:
npm install
Inicie o servidor de desenvolvimento:
npx expo start
Estes comandos pressupõem que a estrutura do projeto Expo já esteja presente no repositório.

Princípios do projeto
1. Clareza: informações e metas fáceis de entender.
2. Flexibilidade: hábitos e lembretes configuráveis.
3. Transparência: estimativas nutricionais não são apresentadas como medições exatas.
4. Privacidade: dados pessoais devem ser tratados com cuidado e controles claros.
5. Consistência: componentes e padrões visuais compartilhados por toda a experiência.
Aviso
O BEMIA é um projeto de software em desenvolvimento. Ele não substitui aconselhamento médico ou nutricional individualizado. Funcionalidades como análise automática de refeições, sincronização com serviços de saúde e pagamentos dependem de implementação e validação próprias.
